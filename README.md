# 🧼 NettPro – Site vitrine d'une entreprise de nettoyage

Bienvenue sur **NettPro**, le site web d'une entreprise de nettoyage.

---

## 🌐 Aperçu du site

Ce site présente les services de nettoyage NettPro, avec plusieurs sections essentielles :

- Accueil (`index.html`)
- Contact
- Demande de devis
- Gestion des cookies
- Espace administration
- Ajout de matériel et de produits
- Page formation

---

## 📂 Structure du projet

Voici quelques-uns des fichiers inclus dans le projet :

- `index.html` : page d'accueil
- `contact.html` : formulaire de contact
- `devis.html` : formulaire de demande de devis
- `cookies.html` : politique de cookies
- `administration.php` : espace d'administration
- `ajouter_materiel.php` / `ajouter_produit.php` : gestion des stocks
- `index.css` : feuille de style principale
- `favicon.ico` : icône du site

---

Pour un rendu visuel complet :
